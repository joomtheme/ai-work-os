# Contributing to AI Work OS 🚀

Thank you for your interest in building the future of human + AI collaboration.

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Add tests where applicable
5. Open a Pull Request

```bash
git checkout -b feature/my-feature
```

## Contribution Areas

- AI Agents
- Mission workflows
- Developer SDK
- Integrations
- Documentation
- User experience

## Pull Requests

Please include:

- What changed
- Why the change is needed
- How it was tested
- Screenshots or demos when relevant

## Development Principles

- Keep changes focused
- Prefer simple and maintainable solutions
- Document new features
- Respect user control and safety boundaries

Let's build the AI workforce platform together. 🔥
